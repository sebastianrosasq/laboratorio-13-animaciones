# Laboratorio 13 Animaciones en Jetpack Compose

Proyecto Android con cinco ejercicios de animación y el codelab adicional

- `app`: visibilidad, color, tamaño y posición, contenido y prototipo de videojuego
- `codelab`: módulo `finished` oficial de Android adaptado a las versiones de Gradle y dependencias del proyecto, conserva su licencia Apache 2.0
- `evidencias`: capturas del emulador durante las pruebas
- `videos`: grabaciones de las interacciones reales

Abrir el proyecto en Android Studio y seleccionar `app` o `codelab`, o compilar con `gradlew.bat :app:assembleDebug :codelab:assembleDebug`

Codelab original: https://developer.android.com/codelabs/jetpack-compose-animation?hl=es-419
Código original: https://github.com/android/codelab-android-compose/tree/main/AnimationCodelab/finished
